# Тесты для КУ

## Кодировка наименования файла тестирования

[ГГ]_[ХХХХХ]_[АбривеатураРаздела]_[НаименоаниеРаздела]

1. ГГ - группа тестов, определяет порядок выплнения группы тестов в очереди тестовых условий.
    - 00 - группа тестов функциональных интерфейсов разделов (ФИ)
    - 01 - группа тестов функциональных интерфейсов разделов в форме объекта Группы (ФИО)
    - 02 - группа тестов форм объектов, основной формы функционального объекта
2. ХХХХХ - префикс наименования файла теста определяющий порядок исполнения в очереде тестовых условий. Шаг между кодми равен 10 
3. АбривеатураРаздела - сокращенное наименование раздела системы, функционала, интерфейса, функции
    - ФИ  - **функциональный интерфейс списка**, основная форма списка функциональных объектов
    - ФИВ - **функциональный интерфейс выбора**, основная форма списка выбора объектов
    - ФО  - **форма объекта**, основная форма функционального объекта
    - КИ  - **контекстный интерфейс**, функциональный интерфейс функционала встроенный в форму объекта (ФО), данные, в которои ограниченный владельцем формы.
4. НаименоаниеРаздела - наименование функционального раздела системы
    - ОГ     - Объекты Группы
    - Инвест - Инвестиции
    - Инвесторы - Инвесторы 
    - Вклад - Вклад в имущество
    - Актив - Активы
    - ДВ    - Дивиденды/Выплаты
    - КОУ   - Оргны корпоративного управления
    - ПКМ   - План корпоративных мероприятий
    - Поруч - Поручения по протоколу
    - УчНКО - Участие в НКО
    - ДоЗ   - документы о Заинтересованности
