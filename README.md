# Тесты для КУ

## Кодировка наименования файла тестирования

[ХХХХХ]_[АбривеатураРаздела]_[НаименоаниеРаздела]

1. ХХХХХ - префикс наименования файла теста определяющий порядок исполнения в очереде тестовых условий
2. АбривеатураРаздела - сокращенное наименование раздела системы, функционала, интерфейса, функции
    - ФИ  - функциональный интерфейс списка, основная форма списка объекта
    - ФИВ - функциональный интерфейс выбора, основная форма списка выбора объекта
    - ФИО - функциональный интерфейс списка в организации, основная форма списка объекта в фомле справлчника Организации
    - ФО  - форма объекта, основная форма объекта
4. НаименоаниеРаздела - наименование функционального раздела системы
